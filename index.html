Подключение к интернету

Для реальных гостей нужна бесплатная тестовая инфраструктура Supabase Realtime. Укажи адрес проекта и publishable key, а не секретный ключ.

Состояние подключения появится здесь после нажатия кнопки.
🔓 Для прототипа комнаты публичные: код — не пароль. Python-сервер ограничивает музыкальные команды секретом ведущего, но заявки на вход и чат пока защищены только интерфейсом. Не используй для публичных комнат. Не делись полной адресной строкой с #host= и личными данными. Приглашай только кнопкой ниже. Позже понадобятся аккаунты и серверные права.
📂 Как включить загрузку своих MP3?

1. В Supabase: Authentication → Sign In / Providers → Anonymous Sign-Ins → Enable.

2. Storage → New bucket → имя room-audio; включи Public и задай лимит 15 MB для файлов.

3. В SQL Editor выполни SQL-политику из файла supabase_music_setup_v06.sql, который идёт рядом с HTML.

⚠️ Это тестовый вариант: песни общедоступны по ссылке, а анонимные пользователи могут расходовать место. Для публичного сервиса понадобятся аккаунты, антиспам и квоты.

Сначала введи правильные Project URL и Publishable key, затем скачай файл index.html и размести его на хостинге. Друзьям больше не придётся вводить настройки сервера.
